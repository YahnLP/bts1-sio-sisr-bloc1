# Corrigés (réservés à l'enseignant)

Ce dossier est **hors du site publié** (il n'est pas dans `docs/`). Il contient, ​séance par séance, les corrigés des TP et les grilles d'évaluation.

Convention de nommage : `Sxx-corrige.md` (exemple : `S06-corrige.md`).

> Un dépôt public reste lisible par tout le monde : si les corrigés ne doivent pas être visibles des étudiants, il faut les tenir dans un ​dépôt privé ou en local.
