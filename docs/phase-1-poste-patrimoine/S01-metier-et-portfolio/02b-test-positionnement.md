## MODULE B — Logique et Raisonnement (10 points)

*Ces questions évaluent votre capacité à raisonner méthodiquement — pas vos connaissances techniques*

**B1.** Un technicien reçoit une alerte : "le serveur web ne répond plus". Il doit déterminer si c'est un problème réseau ou applicatif. Quelle est sa première action logique ?
- A. Redémarrer le serveur immédiatement
- B. Vérifier si d'autres machines sur le réseau sont accessibles
- C. Appeler l'éditeur du logiciel
- D. Chercher une solution sur Internet

**B2.** Un script doit créer un dossier uniquement s'il n'existe pas. En pseudo-code :
```
SI le_dossier_existe ALORS
    [instruction A]
SINON
    [instruction B]
FIN SI
```
Que contient l'instruction B ?
- A. "Supprimer le dossier"
- B. "Ne rien faire"
- C. "Créer le dossier"
- D. "Afficher une erreur"

**B3.** Dans un réseau, 5 équipements sont connectés. Chaque équipement doit pouvoir communiquer avec tous les autres. Combien de connexions point à point sont nécessaires au minimum ?
- A. 5
- B. 10
- C. 15
- D. 20

**B4.** Une règle de pare-feu dit : "Autoriser le trafic TCP entrant sur le port 443 depuis n'importe quelle source." Quel service est ouvert ?
- A. SSH
- B. FTP
- C. HTTP
- D. HTTPS

**B5.** Un fichier texte a une taille de 1 ko. Après compression, il fait 300 octets. Quel est le taux de compression approximatif ?
- A. 30%
- B. 70%
- C. 300%
- D. Il faut plus d'informations

**B6.** Dans une adresse IP `192.168.1.50/24`, combien d'hôtes peuvent coexister sur ce réseau ?
- A. 50
- B. 24
- C. 254
- D. 256

**B7.** Une boucle `for i in range(1, 6)` en Python s'exécute combien de fois ?
- A. 4
- B. 5
- C. 6
- D. 7

**B8.** Si A implique B, et B est faux, que peut-on conclure sur A ?
- A. A est vrai
- B. A est faux
- C. A peut être vrai ou faux
- D. On ne peut rien conclure

**B9.** Un technicien suit les étapes : 1) vérifier les logs, 2) reproduire l'erreur, 3) identifier la cause racine, 4) appliquer le correctif, 5) tester. Cette démarche s'appelle :
- A. Méthode de déploiement
- B. Procédure de sauvegarde
- C. Méthode de résolution de problème (troubleshooting)
- D. Procédure d'escalade

**B10.** Un administrateur doit créer 50 comptes utilisateurs avec les mêmes paramètres de base. La méthode la plus efficace est :
- A. Créer chaque compte manuellement dans l'interface graphique
- B. Écrire un script qui lit un fichier CSV et crée les comptes automatiquement
- C. Demander à chaque utilisateur de créer son propre compte
- D. Créer un seul compte et le partager entre tous les utilisateurs
