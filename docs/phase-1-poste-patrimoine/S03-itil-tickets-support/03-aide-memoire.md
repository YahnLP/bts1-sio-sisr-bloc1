## Les quatre types de sollicitations

| Type | Définition | Exemple |
|---|---|---|
| **Incident** | Interruption ou dégradation d'un service | Le PC ne démarre plus |
| **Problème** | Cause d'un ou plusieurs incidents | Pourquoi cinq PC ont-ils planté ? |
| **Changement** | Ajout, modification, retrait d'un élément | Installer une application |
| **Demande de service** | Demande standard, sans panne | Créer un compte |

## Priorité

**Priorité = impact × urgence** (voir la matrice de ton organisation).

## Niveaux de support

| Niveau | Rôle |
|---|---|
| N1 | Accueil, qualification, résolution des cas courants |
| N2 | Technicien, accès étendus |
| N3 | Expert, éditeur |

**Un bon ticket :** titre précis · utilisateur · description reproductible · **impact** · actions déjà faites · priorité · capture.
