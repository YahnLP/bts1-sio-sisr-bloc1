<details markdown="1">
<summary>Éléments de réponse Q3</summary>

L'inventaire de parc ne surveille pas l'activité personnelle : il recense les logiciels installés et la configuration matérielle pour des raisons légitimes (licences, sécurité, conformité). Il doit figurer dans la **charte informatique** que les utilisateurs signent. Le RGPD impose une information préalable des personnes dont les données sont traitées ; un inventaire sur un équipement professionnel est en général couvert par la charte. Le serveur doit être sécurisé (HTTPS, accès restreint).
