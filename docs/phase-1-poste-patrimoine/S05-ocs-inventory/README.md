## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Expliquer** l'intérêt d'un inventaire automatique et l'architecture client/serveur d'OCS ;
2. **Installer** l'agent sur un poste Windows et **forcer** un inventaire ;
3. **Retrouver** son poste dans la console et **lire** les informations collectées ;
4. **Comparer** OCS avec d'autres outils de gestion de parc ;
5. **Situer** le lien entre OCS et GLPI.
