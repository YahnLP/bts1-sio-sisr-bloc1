## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Décrire** l'architecture de GLPI et ses profils d'utilisateurs ;
2. **Créer**, **affecter**, **escalader** et **clôturer** un ticket ;
3. **Lire** un tableau de bord de suivi ;
4. **Expliquer** le lien entre l'inventaire (OCS) et les tickets (GLPI) ;
5. **Installer** GLPI à partir d'un script (annexe).
