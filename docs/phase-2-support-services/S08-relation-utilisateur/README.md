# S08 – Communiquer avec l'utilisateur : accueil, écoute et écrit professionnel

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 1re année – bloc 1 |
| **Séance** | S08 (séance 8 sur 19) – Phase 2 |
| **Durée** | 4 heures |
| **Prérequis** | S03 (niveaux de support). |
| **Matériel** | Fiches de jeu de rôle |
| **Compétences travaillées** | B1.2 · B1.6 (voir [le référentiel](../../ressources/referentiel.md)) |

> [!NOTE]
> **Question qui guide la séance :** *« Un utilisateur énervé n'a pas besoin d'un cours de réseau : que lui dit-on, et comment ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Identifier** le profil de son interlocuteur et **adapter** son discours ;
2. **Structurer** un appel de support en six phases ;
3. **Désamorcer** une situation tendue (méthode DESC) ;
4. **Rédiger** un courriel de support clair et poli ;
5. **Reformuler** sans vulgariser à l'excès.
