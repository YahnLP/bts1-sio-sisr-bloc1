| **Durée** | 4 heures |

| **Compétences travaillées** | B1.5 · B1.1 · B1.4 (amorcée) (voir [le référentiel](../../ressources/referentiel.md)) |

> [!NOTE]
> **Question qui guide la séance :** *« Que propose le service informatique, à qui, avec quel engagement : comment le dire de façon claire ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Définir** un catalogue de services et ses deux vues (utilisateurs, techniciens) ;
2. **Rédiger** une fiche de service ;
3. **Classer** des services en catégories ;
4. **Situer** le catalogue dans GLPI ;
5. **Décrire** le cycle de vie d'un service.
