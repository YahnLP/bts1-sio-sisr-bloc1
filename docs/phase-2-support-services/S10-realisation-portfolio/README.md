| Élément | Détail |
|---|---|

> [!NOTE]
> **Question qui guide la séance :** *« Comment raconter une mission pour qu'un jury comprenne ce que j'ai fait, moi, et comment le prouver ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Décrire** le contenu du dossier numérique de l'épreuve E5 (portfolio, tableau de synthèse, attestations) ;
2. **Structurer** une fiche de réalisation professionnelle (contexte, mission, réalisation, compétences, résultats, retour d'expérience, preuves) ;
3. **Distinguer** ce qui prouve une action et ce qui la décrit ;
4. **Rédiger** une première fiche à partir d'une séance ou d'une mission en entreprise ;
5. **Relire** la fiche d'un camarade avec une grille.
