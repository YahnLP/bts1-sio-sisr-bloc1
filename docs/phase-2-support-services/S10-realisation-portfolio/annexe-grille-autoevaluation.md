# Annexe – Grille d'auto-évaluation d'une fiche de réalisation

*BTS SIO SISR 1re année – Bloc 1 – S10*

À remplir **avant** de remettre la fiche. Chaque critère : **non**, **partiel** ou **oui**.

| Critère | Non | Partiel | Oui |
|---|---|---|---|
| Le contexte est compréhensible par un jury qui ne connaît pas l'organisation | | | |
| La mission est précise et délimitée | | | |
| La réalisation utilise « je » et non « on » | | | |
| Au moins une décision est justifiée techniquement | | | |
| Une difficulté est honnêtement mentionnée avec sa solution | | | |
| Chaque compétence citée est justifiée par une action concrète | | | |
| Les résultats sont **vérifiables** (pas seulement « ça a marché ») | | | |
| Le retour d'expérience va au-delà du résumé | | | |
| La fiche fait deux pages au maximum, hors preuves | | | |
| Chaque affirmation importante renvoie à une preuve existante | | | |

**Nombre de « oui » :** ______ / 10

- **9 ou 10** : la fiche est prête à entrer dans le portfolio.
- **6 à 8** : reprends les points « partiel » avant de la verser.
- **Moins de 6** : reprends les rubriques faibles avec le [canevas guidé](annexe-canevas-realisation.md).

> [!NOTE]
> Cette grille est un **outil de formation**. Elle n'est pas la grille d'aide à l'évaluation de la circulaire nationale (voir la page [Épreuve E5](../../ressources/epreuve-e5.md)).
