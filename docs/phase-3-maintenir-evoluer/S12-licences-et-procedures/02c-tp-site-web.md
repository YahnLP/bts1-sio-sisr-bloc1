# TP – Contrôler la conformité du site de SimIO SARL

*BTS SIO SISR 1re année – Bloc 1 – S12*

## But

Contrôler un site vitrine et rédiger les mentions légales manquantes. Durée : environ 20 minutes.

## Contraintes

- Les informations ci-dessous sont **fictives**. Pour les mentions légales, utilise les champs du modèle sans inventer de numéro réel.
- Une seule action à la fois, un constat noté pour chaque point.

## Le site à contrôler

Le site vitrine de SimIO SARL présente les services de l'entreprise. Voici ce que tu constates :

1. Le pied de page contient seulement « © 2026 SimIO ».
2. La page d'accueil affiche une photo d'équipe copiée depuis un moteur de recherche, sans indication de source.
3. Les liens de téléchargement sont intitulés « cliquez ici ».
4. Le texte de description est en gris **#AAAAAA** sur fond blanc.
5. Un formulaire de contact collecte nom, courriel et message, sans aucune information sur l'usage des données.
6. Les fichiers téléchargeables s'appellent `Procédure DHCP finale (2).pdf`.
7. Les images n'ont pas de texte alternatif.
