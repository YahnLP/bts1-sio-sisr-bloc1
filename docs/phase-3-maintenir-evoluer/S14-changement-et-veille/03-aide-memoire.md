## Trois types de changements

| Type | Exemple |
|---|---|
| Standard | Pré-approuvé, risque connu (changer un mot de passe) |
| Normal | Évalué et approuvé (nouvelle application) |
| Urgent | Corriger une panne grave, procédure accélérée |

## RFC

Identification · description · **justification** · impact et **risque** · plan de mise en œuvre · plan de **retour arrière** · tests · communication · validation.

## Veille

Sources fiables · agrégateur (flux RSS) · alertes · **routine courte et régulière** · notes datées dans le portfolio.
