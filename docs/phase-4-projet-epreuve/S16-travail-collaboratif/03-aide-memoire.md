## Git

| Besoin | Commande |
|---|---|
| Initialiser | `git init` |
| Voir l'état | `git status` |
| Préparer | `git add fichier` |
| Valider | `git commit -m "message"` |
| Historique | `git log --oneline` |
| Différences | `git diff` |
