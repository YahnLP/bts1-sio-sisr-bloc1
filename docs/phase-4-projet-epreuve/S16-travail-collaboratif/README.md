## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Expliquer** les enjeux et les règles du travail collaboratif ;
2. **Installer** un wiki technique (DokuWiki) et **structurer** ses pages ;
3. **Utiliser** Git pour suivre des fichiers (init, add, commit, log) ;
4. **Décrire** la gestion des terminaux mobiles (BYOD, gestion centralisée) et les bonnes règles d'usage ;
5. **Choisir** un outil de partage de documents selon des critères.
