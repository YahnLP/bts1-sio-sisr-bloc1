> [!NOTE]
> **Question qui guide la séance :** *« Le support fonctionne : comment montrer qu'il règle de vrais problèmes et que les utilisateurs savent s'en servir ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Résoudre** trois tickets réalistes de bout en bout ;
2. **Rédiger** un guide utilisateur avec tutoriels et FAQ ;
3. **Documenter** le projet dans le wiki (architecture, installation, incidents) ;
4. **Présenter** le projet en quelques minutes ;
5. **Rédiger** une fiche de réalisation pour le portfolio.
